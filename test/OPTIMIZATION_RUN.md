# 后续优化结果与恢复范围

2026-10-23 整理。下表来自 2026-10-22 对话中实际工具输出的历史记录；本次没有重新运行真实 embedding、重排或 Whisper。五视频的完整 gold、逐题明细、索引和原聚合 JSON 未完整恢复，以下是恢复的汇总，不是新产生的原始评测报告。

历史范围：5 个视频完整英文字幕，6 小时 1 分 13 秒，8383 条、805 块；80 道 agent 草稿（64 可回答、16 无答案），独立人工审核为 0。所有视频共同检索，未按答案视频过滤，未启用 Ollama 生成问题增强。

| 配置 | 原小块 Recall@30 | 扩展证据覆盖@30 | 最终 Hit@5 | MRR@5 |
|---|---:|---:|---:|---:|
| 轻量＋邻句 | 81.25% | 92.19% | 85.94% | 0.6333 |
| 轻量＋标题 | 81.25% | 92.19% | 84.38% | 0.5974 |
| 轻量＋时间去重 | 81.25% | 92.19% | 84.38% | 0.6320 |
| BGE 组合＋邻句 | 85.94% | 93.75% | 90.63% | 0.7609 |

BGE 最终 Hit 为 58/64，Wilson 95% 区间约 81.02%–95.63%；相对轻量改善 3 题、退步 0 题，配对差值区间约 0 至 +10.94 个百分点。该样本区间不覆盖视频相关性、草稿标签错误或反复调参。

BGE 组合为 BGE-M3＋bge-reranker-v2-m3，embedding/rerank 预算 1024/2048；轻量为 BGE-small-en-v1.5＋MiniLM-L-6，预算 256/512。虽然历史记录核对了同一批固定分块，预算仍不同，不能把收益完全归因于模型。原小块 95% 目标仍未达到；扩展覆盖不能替代原块召回。

标题单变量实验改善 1 题、退步 2 题；时间去重改善 0 题、退步 1 题，均未设为默认。所有配置无拒绝阈值时都向 16/16 无答案题返回结果；没有运行工作台 LLM，不能解释为 LLM 已被测出全部错答。

历史 top-5 加引用头的 embedding tokenizer token 最大值分别为：轻量 1225、标题 1225、时间去重 1225、BGE 1285。这不是工作台 LLM 的 token 数，接入仍需按实际 tokenizer 核验总预算。

参考为官方字幕，未独立逐字听写，切点可能有误差；只有两个英语片段，不能代表公司中英混杂场景。合成英文术语图曾识别 7/8 个词，CrewAI → CrewAl，放大两倍仍错；这不是公司视频准确率。词表可能补回术语，同时干扰其他文字，不能只看正面指标。
