## 当前方案

1. 本地 ffmpeg 抽帧，RapidOCR 保存时间、置信度和截图；候选词人工修正并批准。
2. Whisper 显式选择无词表或局部确认词表，限制提示 token，输出原始转录与审计，不用 OCR 字符串替换语音证据。
3. 语义/时间窗分块，Ollama 原文摘要与带证据的问题；Dense 编码原文，生成问题仅辅助 BM25。
4. Qdrant embedded + jieba/BM25 + Dense，RRF 融合后最多 30 条重排到默认前 5 条。
5. 邻句扩展默认关闭，受单条时间和 token 预算约束；原块召回与扩展覆盖分开报告。
6. FastAPI /search 输出原文、摘要和时间引用；评估按 type/video/split 汇总。
